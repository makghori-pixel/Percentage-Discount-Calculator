# Percentage & Discount Calculator

A lightweight, fast, and fully responsive single-page web tool to calculate percentage increases, decreases, original prices, and retail discounts in real-time. 

Built with zero external dependencies, running 100% client-side in the browser.

---

## Features

- **Discount Calculator:** Calculate final price, total savings, and tax instantly.
- **Percentage Change:** Find percentage increase or decrease between two values.
- **Reverse Percentage:** Easily determine original prices before a discount or tax was applied.
- **Fast & Lightweight:** Pure HTML5, CSS3, and Vanilla JavaScript with instantaneous calculations.
- **Responsive Design:** Optimized for mobile phones, tablets, and desktop displays.
- **Privacy-First:** All calculations run locally in the user's browser—no data is sent to a backend server.

---

## Tech Stack

- **HTML5** – Structured, semantic markup with accessible inputs.
- **CSS3** – Modern layout using Flexbox/CSS Grid and responsive design.
- **Vanilla JavaScript (ES6+)** – Client-side logic for real-time calculations without frameworks.
